# Goal: LP（app/page.tsx）リデザイン

## Vision

**問題**: 入口であるLPだけが「広告・キャンペーンの文法」（濃い紫→青グラデ＋白文字＋ガラスカード＋絵文字）で作られ、onboarding以降の「静かな内省空間」（淡い `bg-aurora`＋ダーク文字＋白カード＋線画SVG）と情緒が断絶している。結果、①初見ユーザーに"占いアプリ"の印象を与え（彩度の高いグラデ＋星マーク✨が禁止カテゴリの視覚記号と衝突）、②第一声が「診断」=分析フェーズから入り非交渉シーケンス（共感→安心→分析→行動）に違反し、③COCOSiLの趣旨が「4診断×AIで統合レポート」という機能説明でしか語られず、体験の約束として伝わらないまま離脱を招いている。この「入口の世界観・情緒・趣旨の不一致」を解消する。

**ユーザー**: COCOSiLに初めて訪れる25-35歳の若手社会人。特に「占いアプリは飽きた、でも自分のことは知りたい」層。職場・恋愛・家族の対人関係で消耗し、根拠のある自己理解を求めるがスピリチュアル/占い的なものには冷めている。SNS経由の流入を含む。

**代替手段**: 現状のLPのまま。初見ユーザーは派手なグラデ＋星マークから「また占い系か」と判断し趣旨が伝わる前に離脱、あるいはGoogle登録まで進んでも次のonboardingで急に静かな内省トーンに切り替わり「釣られた」と感じて初回離脱する。

**6ヶ月後の成功像**: LPを開いた瞬間にonboarding以降と同じ「静かで根拠のある自己理解空間」の世界観が伝わり、初見ユーザーが"占い"ではなく"自分のトリセツが作れるアプリ"として趣旨を理解し、違和感なくonboardingへ進んでいる。

## Outcome

**何が変わるか**:
- LPの背景・文字色・カードがonboardingと同一の淡いオーロラ世界観に統一され、画面遷移時の情緒の断絶が消える
- 絵文字4種がonboarding同一画法のインライン線画SVGに置き換わり、ブランドの世界観が一貫する
- 「体験の流れ（共感→安心→分析→行動）」と「根拠による差別化コピー」がLPに追加され、趣旨が機能説明でなく体験の約束として伝わる

**測定方法**:
- 主（定性）: えんまさによるプレビューURL目視で「LP→onboardingの世界観連続性」「占い感の排除」「趣旨の伝達」を確認（壊れ方パターン③ UX断絶の確認手段）。加えて `language-design` スキルで差別化コピーの禁止語・否定形チェック
- 従（定量）: 計測基盤が整い次第、LP→onboarding遷移率と7日以内再訪率（PMF基準30%）を継続モニタリング。本タスクの直接の合否は定性確認で判定

**期限**: なし（継続的に）

**最低ライン**: 設定なし（[X] 保留）

## Eval criteria

- [ ] #1 LP背景が `bg-aurora`・文字色 #1e1a3c 系になり、onboardingと同一の淡い世界観で表示される
- [ ] #2 体験の流れ（共感→安心→分析→行動）が視覚ステップとしてLPに表示される（哲学を順序で体現）
- [ ] #3 根拠による差別化コピーがLPに表示される（「根拠のある自分のトリセツ」方向／否定形・禁止語なし）
- [ ] #4 4体系アイコンが絵文字からonboarding同一画法（1.5px単色線画 #a78bfa ＋ラベンダー円）のインラインSVGに置換され、占いの記号語彙（星・干支等）を避け各体系が観るものを抽象化している
- [ ] #6 CTAが既存 `gradientBtnStyle`（purpleグラデ）に統一されている
- [ ] 失敗ケース: LP→onboardingを連続で見て世界観が途切れる、またはLP単体で「占いアプリ」の印象を与える（彩度の高いグラデ／星・干支などの占い記号／絵文字が残存）状態は不合格

**確認方法**: 人間レビュー（えんまさ）。プレビューURL または `pnpm dev` でLP→onboardingを連続目視。UIコピー追加を含むため **Gate 2（えんまさ承認）対象**。差別化コピーは `language-design` スキルで禁止語・否定形を事前チェックしてから提出。

**劣化検出**: 未整備（[X] 保留 — HARNESS_HEALTH.md に記録）。将来候補＝Visual Regression（Playwrightスクショ比較）、LPコピーの禁止語を `lib/constitution/banned-words.ts` 参照で検査する単体テスト。

## 設計中枢チェック（5問リトマス）

- Q1 無明を晴らすか: ○ 趣旨（根拠ある自己理解の入口）を初見で伝える
- Q2 三毒を増幅しないか: ○ 彩度・煽り訴求を排し、静かな引力（流体オーブ）で構成
- Q3 共感→安心→分析→行動の順序: ○ LPで「体験の流れ」として順序を体現、第一声を分析語から外す
- Q4 大我への移行支援: ○ 占い的な"当てる"訴求でなく自己観察の入口として提示
- Q5 良い人間関係に寄与: ○ 自己理解を対人関係の入口として位置づけるトーン

## 実装メモ（議論より・要件確定後の指針）

- 背景置換: `linear-gradient(160deg,...)` → 既存 `bg-aurora` クラス再利用
- 流体オーブ: reassuranceの `FluidOrb` を `components/` に共有コンポーネント化しLP・reassuranceで共有
- アイコン（2026-06-01 確定）: `components/icons/` にインラインSVG 4種を切り出し。全て viewBox 0 0 40 40 / stroke #a78bfa / 1.5px / ラベンダー円 rgba(167,139,250,0.12) 内包
  - MBTI = 角丸正方形を4象限に割る格子（性格の次元。人型・星を回避）
  - 12星座 = 傾いた楕円軌道＋移動点＋中心点（天球の運行。星マーク回避）
  - 60種動物分類 = 足あと（抽象パッド：楕円＋指3つ。特定動物を描かない）
  - 六星占術 = 円環＋60°間隔の6本のtick＋中心点（6分割の周期構造。六芒星・干支を回避）
- 意味はテキスト（ラベル＋短い補足）が担い、アイコンは世界観を担う
- CTA: 白ボタン → `gradientBtnStyle`
