## 1. 再設計の要旨

substring 一致＋embeddingスタブ（0.5固定）を廃し、**Trunks 値 → 観察軸への理論的「順序重み」行列**でスコアを導出する。

設計3原則（議論で確定）:
- **① Map, Don't Match.** — 照合せず写像する
- **② Spread Before Profile.** — 散らしてから際立たせる
- **③ Ordinal Roots, No Decoration.** — 根拠ある順序尺度のみ、連続値の装飾的微調整は禁止

## 2. 順序尺度の定義

| 記号 | 意味 | 数値 |
|---|---|---|
| `++` | 強い正の親和（強+） | +2 |
| `+` | 弱い正の親和（弱+） | +1 |
| `0` | 中立 | 0 |
| `−` | 弱い負の親和（弱−） | −1 |

> 連続小数は使わない。3〜5段階の順序値に限定することで「なぜこの軸が高いか」を理論で説明でき（説明可能性＝腑落ちの前提）、分散稼ぎの装飾を構造的に排除する。

## 3. 観察軸（列）の略号

| 略号 | 軸ID | label | パンチャ起源 |
|---|---|---|---|
| EMB | embodied_pattern | 身体・気質パターン | rūpa（色） |
| EMO | emotional_response | 感情反応パターン | vedanā（受・内） |
| COG | cognitive_style | 認知スタイル | saṃjñā（想） |
| MOT | motivation_drive | 動機エネルギー | saṃskāra（行） |
| REL | relational_mode | 対人モード | 受（対人）+ 行（関係） |

### 4.6 注記：COG（認知スタイル）の分散特性

COG は重み極性が他軸より穏やかな軸である。実データ10件（MBTI欠落・3体系）での検証で COG std=0.150 と他軸（EMO .281 / EMB .258）より低く出たが、これは**行列の欠陥ではなく以下の構造による**：

- 軸ごと理論 min/max 正規化のため、データセットが COG の両極（高COG型 `nt×air×−` と 低COG型 `sp×water`）を同時に含まない限り分散は中庸に出る。
- **COG を最も分けるのは keirsey の `nt`(+2) ↔ `sp`(−1)** であり、MBTI 必須の本番ではこの認知差で分散が広がる。
- 下限を恣意的に下げて分散を稼ぐ調整は検証の結果**逆効果**（レンジ拡大で正規化値が中央へ圧縮）かつ原則③「No Decoration」違反のため**行わない**。

→ COG は理論的に正直な現状値（sun=0 / fullMoon=0）を維持する。

## 5. 導出フロー（3段）

```
1. accumulate（合算）
   raw[axis] = Σ_trunk  W[trunk.value][axis]
   （phase は指定時のみ加算。未指定なら4体系のみ）

2. normalize（軸内正規化＝ユーザー間分散の確保）★必須
   norm[axis] = (raw[axis] − MIN[axis]) / (MAX[axis] − MIN[axis])  → [0,1]
   MIN/MAX は行列から決まる理論的下限・上限（事前計算・定数）

3. profile（軸間プロファイル＝デコボコ強調）△任意
   軸間順位差は step1+2 で自然に生じるため、原則 step3 は適用しない。
   適用する場合も「軸内分散を食い潰さない範囲」に限定（Spread Before Profile）。
```

**axisScores（出力 [0,1]）= norm[axis]**。phase 未指定時の MIN/MAX と指定時の MIN/MAX は別系列で持つ（4体系のみ / 5要素）。

### v3 embedding 余地

interface は `score = α · structural + (1−α) · embedding` を維持。現フェーズは embedding を使わず `structural`（= norm）をそのまま採用。v3 で embedding を後付け係数として差し込めるよう型だけ残す。

## 6. 分散の手計算検証（2ペルソナ）

理論的 MIN/MAX（4体系のみ、phase 無し）:

| 軸 | MIN | MAX | レンジ |
|---|--:|--:|--:|
| EMB | −2 | 6 | 8 |
| EMO | −3 | 6 | 9 |
| COG | −1 | 6 | 7 |
| MOT | −3 | 6 | 9 |
| REL | −1 | 6 | 7 |

**ペルソナA（INTJ / fire / sun / +）:**
raw = EMB 3, EMO −1, COG 3, MOT 6, REL 2
→ norm = EMB .625, EMO .222, COG .571, MOT **1.00**, REL .429
→ 順位: MOT > EMB > COG > REL > EMO（spread 0.78）

**ペルソナB（ISFJ / water / fullMoon / −）:**
raw = EMB 0, EMO 3, COG 1, MOT −2, REL 4
→ norm = EMB .250, EMO .667, COG .286, MOT .111, REL **.714**
→ 順位: REL > EMO > COG > EMB > MOT（spread 0.60）

**結論**: 2人で軸順位が完全に別形状。**①ユーザー間で散る ②軸間に順位差**を両立し、≈0.20 への潰れは解消。同一入力は決定論的に同値（純粋ルックアップ＋四則演算）。
