## 3. 表記差分 6 体（regex 正規化で救済）

Q5b 呼称が公式とほぼ同じだが軽微な表記差分のため、機械正規化で公式呼称に変換して採用する。

| 公式 ID | 公式呼称 | Q5b 呼称 | 差分 | 正規化ルール |
|---:|---|---|---|---|
| 4 | フットワークの軽い**子守熊** | フットワークの軽い**こあら** | こあら ⇄ 子守熊 | `replace(/こあら/g, '子守熊')` |
| 5 | 面倒見**のいい**黒ひょう | 面倒見**の良い**黒ひょう | 良い ⇄ いい | `replace(/良い黒ひょう/g, 'いい黒ひょう')` |
| 9 | 大きな志を**もった**猿 | 大きな志を**持った**猿 | 持った ⇄ もった | `replace(/志を持った/g, '志をもった')` |
| 10 | 母性豊かな**子守熊** | 母性豊かな**こあら** | こあら ⇄ 子守熊 | (同上) |
| 22 | 強靭な翼を**もつ**ペガサス | 強靭な翼を**持つ**ペガサス | 持つ ⇄ もつ | `replace(/翼を持つ/g, '翼をもつ')` |
| 33 | **活動的な子守熊** | **活動的なこあら** | こあら ⇄ 子守熊 | (同上) |

**救済語数**: 6 × 8 = **48 語**

### 正規化 TypeScript 実装案

```typescript
// lib/data/three-layer-vocab/twigs/animal-name-normalize.ts
export const ANIMAL_NAME_NORMALIZE_RULES: Array<[RegExp, string]> = [
  [/こあら/g, '子守熊'],
  [/良い黒ひょう/g, 'いい黒ひょう'],
  [/志を持った/g, '志をもった'],
  [/翼を持つ/g, '翼をもつ'],
]

export function normalizeAnimalName(q5bName: string): string {
  return ANIMAL_NAME_NORMALIZE_RULES.reduce(
    (name, [pattern, replacement]) => name.replace(pattern, replacement),
    q5bName,
  )
}
```

## 7. 再発防止策

今後の葉ノード DR では以下を厳守する：

> **公式呼称統一 5 原則（議論ログ_動物60公式呼称統一.md Turn 5）**
> ① Single Source of Truth — lib/data/animal-characters.ts 等の社内 Canonical を必ず確認
> ② Three-Bucket Classification — 完全一致 / 表記差分 / 完全不存在の 3 分類で別ワークフロー
> ③ Machine Normalization for Notation, Human Judgment for Identity — 表記差分は regex 自動、固有名差分は手動判定 + 補完 DR
> ④ Embed Canonical List in DR Prompts — DR プロンプトに正本リストを必ず埋め込み
> ⑤ Self-Healing Drift Test — twigs/{system}.ts と正本データの一致を Vitest で自動検証
