# 議論ログ：3体系診断アイコンの統一（六星占術アイコン再設計）

## 登場人物
- 🎨 桐谷（アイコン/ピクトグラムシステム設計）：UIアイコン設計歴11年。金融・ヘルスケアアプリのアイコンシステムを多数構築。「48pxで死なない記号」が口癖。
- 🔭 環（東洋・西洋占術の記号構造リサーチャー）：象徴学・占術記号史が専門。六星占術・西洋占星術の象徴体系を構造分析。「記号は意味の圧縮」が信条。
- 💅 みさき（ギャル）：IT素人だけど感性が鋭い。実際の診断アプリユーザー。

## Turn 1｜現状認識：なぜ六星だけ浮くのか
3体系（星座／動物／六星占術）は外円フレーム（r=22、薄紫塗り＋ストローク）を共通化しており統一の土台はある。問題は中身の「象徴の次元」がバラバラなこと。星座＝星の散らばり（天体）、動物＝足跡（身体痕跡）、六星占術＝土星リング（天体）。→ 星座と六星占術が両方「天体系」で衝突。さらに土星リングは意味論的に誤配線で、六星占術の核は「土星人・金星人・火星人・天王星人・木星人・水星人」の6つの運命星＝"6という数の秩序"。土星リング単体では「六星」が消える。

**診断：3体系が異なる象徴次元を混ぜているのに、星座と六星だけ同次元で被っている問題。**

## Turn 2｜選択肢の発散：評価軸を立てて案を並べる
評価軸：① 体系性（「六星＝6つの星の秩序」が伝わるか）② 並列差別化（星座の散らばりと被らないか）③ 48px生存性。

- A案：六芒星 → ①✗（魔法陣/霊感連想で被る）③◎
- B案：中心核＋周囲6点を正六角配置 → ①◎ ②◎ ③◎
- C案：同心円の軌道に6惑星点 → ①◎ ②○ ③△（軌道線が48pxで潰れる）
- D案：6本の光条 → ②◎ だが①△（"6"が数えにくい）

→ **B案を採用方向**。「中心＝自己、囲む6点＝運命星」が六星占術の世界観を直接図像化。星座の無秩序な散らばりと「秩序 vs 無秩序」で対比。

## Turn 3｜要件確定：「6が数えられるか」問題
みさきの指摘「6個ってちゃんと数えられないと意味ない」→ 原則「数は規則的配置で初めて"数"として知覚される」。バラけた6点は「散らばり」に退行するので、必ず正六角形頂点に等間隔配置する。

| 優先度 | 要件 |
|---|---|
| 🔴必須 | 6点を正六角形頂点に等間隔配置 |
| 🔴必須 | 中心に1つ大きめの核（自己＝中心の世界観 + 星座との差別化） |
| 🟡推奨 | 中心核と6点を細線で結ぶ |
| 🟢任意 | 6点に強弱（明るい星/暗い星） |
| 🔴必須 | 外円フレームは3体系共通維持 |

## Turn 4｜技術深掘り：gpt-image 2 か、SVG か
桐谷の提言：48pxの幾何アイコンは gpt-image 2 で生成すべきでない。理由＝① Retina対応でラスターは複数解像度管理が増える ② 生成AIは正確な正六角形・正確なブランドHEX・正確な点数(6)を保証できない ③ 既存の星座・動物がインラインSVGなので六星だけラスターにすると質感がズレて統一が壊れる。

法則：**Vector for Meaning, Raster for Mood（意味はベクター、雰囲気はラスター）**。gpt-image 2 が輝くのは reassuranceオーブのような質感勝負の装飾。AGENTS.md の gpt-image-2 方針も「背景/アイコン専用」＝装飾用途で、機能ピクトグラムは想定外。

## Turn 5｜統合：3体系アイコン設計3原則
> ① One Frame, Three Dimensions. — 外円は共通維持。中身は天体（星座）／身体（動物）／数の秩序（六星）と異なる象徴次元に振り分ける。
> ② Order Beats Scatter. — 六星は中心1核＋正六角形6点。星座の散らばりと対比し"6"を前注意的に読ませる。
> ③ Vector for Meaning, Raster for Mood. — 識別記号はSVG、gpt-image 2 はムード生成（背景・オーブ）限定。

明日の一手：SixStarIcon を B案で SVG 再実装／中心核 r=5.5 #a78bfa／6点 正六角形頂点 r=2.5 #c4b5fd（上1点のみ #7c5cfc）／中心〜各点を #ddd6fe 細線／外円フレームは共通値維持／gpt-image 2 は reassuranceオーブの質感側で活用。
