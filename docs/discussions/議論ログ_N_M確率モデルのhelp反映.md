## Turn 1｜現状認識 — N:M 確率モデルは既存「3段階モデル」に何を追加するか

**久保田**： まず事実関係を整理させてください。前回議論（2026-05-28、議論ログ_4体系統合メソッド幹と枝モデル.md Turn 6）で **3段階モデル** を確定しました。① 心の核（4元素=ユング4機能、一生変わらない）→ ② 振る舞いスタイル（MBTI Keirsey 4気質・動物60大分類、生まれつきだが少し変わる）→ ③ 今の時期の出方（六星の四季、時期で変わる）。これはマクロのパンチャ構造を保ったまま、ミクロを Procrustean Mapping から解放した良い決定でした。

しかし、当時は **「② から ① への対応」「② の比率」「③ がどう ② を変調するか」を数式レベルで詰めていなかった**。「NF は水 60% + 火 25% + 風 10% + 土 5%」とラフに書いただけ。これが今回 Q4 で Deep Research された N:M 確率対応モデルで完全に学術的に固まりました。

**真鍋**： 数学的に診断させていただきます。Q4 文書 §5.1 の Layer 2 → Layer 1 (8×4) マトリクスを見ましたが、**これは行確率行列（row-stochastic matrix）です**。各行の総和が厳密に 1.00、各要素が非負。つまり `P[NF→Layer1] ∈ Δ³`（3次元確率単体）に値を取る写像。これが 8 個（SP/SJ/NF/NT/太陽/地球/満月/新月）あるから、**`M ∈ [0,1]^{8×4}` with rowSum = 1** という構造。

しかも Q4 §5.2 で動的変調 `Q(t) ∈ [0,1]^{8×4}` を **アダマール積（要素ごとの積 ⊙）** で適用し、正規化して `P(t) = normalize(S ⊙ Q(t))` とすると言っている。これは数学的にきれいです。なぜなら：

- 静的成分 `S`（生まれ持った構造）と動的成分 `Q(t)`（時期の変調）が **可換的に分離** されている
- アダマール積はテンソル積より弱い演算で、各セルが独立に変調されるので **解釈可能性が高い**
- 行ごとの正規化（Softmax または単純な L1 normalize）で確率分布の保存則を維持できる

前回議論で「②は確率で散らばる、③は②を時期で変化させる関数」と言語化された直観が、**実は静的×動的のアダマール分解という数学的構造そのもの**だったわけです。

**西園寺**： 私が前回提示した距離関数 `α × RuleDistance + (1-α) × EmbeddingDistance, α=0.5` も Q4 §4.3 で **階層的に動的調整** すべきという知見が加わりました：

- Layer 1 ↔ Layer 2 遷移：α = 0.7（**Rule 重視**。象徴体系の不変対応を尊重）
- Layer 2 ↔ Layer 3 遷移：α = 0.3（**Embedding 重視**。言語表現の揺らぎに柔軟）

これは AI 研究の **「深層ほど理論駆動、表層ほど文脈駆動」** という階層性原則（cognitive hierarchy）から導かれます。MIT メディアラボの認知アーキテクチャ研究、Friston の自由エネルギー原理も同じ階層性を主張しています。**つまり「α は単一定数」という前回の暫定設計は捨て、「層遷移ごとに α を変える」に置き換える**べき。

## Turn 4｜技術深掘り — 行確率保存則・テンソル分離・ハルシネーション境界

**真鍋**： 実装上、絶対に守るべき不変条件（invariant）が3つあります。これは Vitest で機械検証可能。

```typescript
// lib/constitution/system-mapping-matrix.ts の不変条件
import { S_LAYER2_TO_LAYER1 } from './system-mapping-matrix';

describe('S matrix invariants', () => {
  test('I1: Row stochasticity — 各行の合計 = 1.00 ± 1e-9', () => {
    for (const row of S_LAYER2_TO_LAYER1) {
      const sum = row.reduce((a, b) => a + b, 0);
      expect(sum).toBeCloseTo(1.0, 9);
    }
  });

  test('I2: Non-negativity — 全要素が [0, 1] 区間', () => {
    for (const row of S_LAYER2_TO_LAYER1) {
      for (const p of row) {
        expect(p).toBeGreaterThanOrEqual(0);
        expect(p).toBeLessThanOrEqual(1);
      }
    }
  });

  test('I3: Cell-level derivation_source coverage — 全 p>0 セルに出典が付与されている', () => {
    // p > 0 のセルには derivation_source 配列が最低1件必要
  });
});
```

これが Layer 2 → Layer 1 の数学的健全性を保証する **Constitution as Code** の核心。Autogenesis（自己進化）が prompt を改善しても、**この行確率行列だけは触らせない**（lib/constitution/immutables.ts 扱い）。

**西園寺**： 動的変調 `Q(t)` の側も不変条件があります：

```typescript
test('Q(t) preserves row stochasticity after Hadamard + normalize', () => {
  const S = S_LAYER2_TO_LAYER1;  // 静的
  const Q_winter = MODULATION_MATRIX['winter'];  // 動的（季節別）

  // アダマール積後に L1 正規化
  const P_t = S.map((row, i) => {
    const modulated = row.map((s_ij, j) => s_ij * Q_winter[i][j]);
    const sum = modulated.reduce((a, b) => a + b, 0);
    return modulated.map(x => x / sum);  // 行ごと正規化
  });

  // P(t) も行確率行列であることを検証
  for (const row of P_t) {
    expect(row.reduce((a, b) => a + b, 0)).toBeCloseTo(1.0, 9);
  }
});
```

**真鍋**： それから、**ハルシネーション境界を数式で定義** できます。LLM が生成した文章を「Layer 2 → Layer 1 の確率分布から逸脱していないか」検証する Eval：

```
LLM_output に登場する 4元素キーワードの頻度分布を F とする。
F を行確率正規化したものを F_norm とする。
KL_divergence(F_norm || P_user) ≤ 0.3
```

KL ダイバージェンス（Kullback-Leibler divergence）が大きいほど **ユーザーの確率分布から外れた創作** をしていることになる。0.3 という閾値は経験的だが、最初の暫定値として機能する。これにより前回議論で「ハルシネーション率 ≤5%」と曖昧に言っていた閾値が、**数式で機械判定可能**になる。

**みさき**： え待って、KL ダイバージェンスってなに？要するに **LLM が生成した文章で、私の確率分布とぜんぜん違う元素を強調してたら、それは捏造だってバレる** ってこと？例えば私 INFP で水60%なのに、レポートで火の話ばっかりしてたら「これおかしい」って自動で検出できる？

**真鍋**： 完璧な理解です。KL ダイバージェンスは「分布Aから見て、分布Bがどれだけズレているか」を測る情報理論的距離。みさんの分布 `(火0.25, 土0.05, 風0.10, 水0.60)` から見て、レポートが `(火0.50, 土0.05, 風0.10, 水0.35)` のように水を弱めて火を強めていたら、KL値が跳ね上がる。

**久保田**： これは抽象法則として極めて重要：

> **法則6: Probabilistic Truth, Verifiable Drift.**
> ユーザーの確率分布を真実とし、LLM の生成文章を分布として再投影、KL ダイバージェンスで逸脱を機械判定する。「占い」的な創作はKL値で物理的にバレる。

> **法則7: Static-Dynamic Tensor Separation.**
> 静的構造 S は不変（Autogenesis 禁止）、動的変調 Q(t) は可変（Autogenesis 改善対象）。両者をアダマール積で合成、L1正規化で確率分布の保存則を維持。

> **法則8: Hierarchical Alpha.**
> α は層遷移ごとに変える。深層（Layer 1↔2）は Rule 重視（α=0.7）、表層（Layer 2↔3）は Embedding 重視（α=0.3）。一律 α=0.5 は捨てる。

> **🎯 Turn 4 法則**: 行確率保存則 + テンソル分離 + KL検証 + 階層別α。これらが F3.1 数学基盤の4本柱。

## ✨ えんまさ向け超要約（専門用語ゼロ）

### この議論で決めたこと（前回の発展形）

**前回（2026-05-28）**: 「人を 3段階で見る」と決めた（核→振る舞い→時期の出方）

**今回（2026-05-28 第2弾）**: その **「3段階の間をどう計算でつなぐか」** を学術と数学で固めた

### 3つの新しい仕掛け

1. **確率の表（8行×4列の行列）** が新しい正式書類になる
   - 例：「Keirseyの理想主義者タイプ（NF）の人は、心の核が **水60% + 火25% + 風10% + 土5%**」
   - これは Greene や Beebe の本から数字を起こした、ちゃんとした学術データ

2. **時期の影響は「色を変える」**
   - 静的な人物像 × 今の季節 = 今の出方
   - 数式で書くと S × Q(t) という掛け算（要素ごと）+ 正規化（合計を1に保つ）
   - 哲学的には「核は変わらない、時期は色付け」のまま

3. **LLM が嘘ついたら数式で機械検出**
   - 「水60%の人」のレポートに、火の話ばっかり書いてあったら **KL ダイバージェンス** が跳ね上がる
   - これで「占いっぽい捏造」を自動で見つけられる
