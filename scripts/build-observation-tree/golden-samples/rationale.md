## 2. 軸境界の解釈（embodied_pattern）

### 採用語（観察軸 Constitution に整合）

`embodied_pattern` = 体質・気質・行動テンポ・エネルギー水準など、身体性に根ざした個人特性。
以下の範疇に限って特徴語を抽出：

| 採用範疇 | 出現例（本サンプル） |
|---|---|
| 体液論的気質（4体液） | 「胆汁質」「粘液質」「冷乾質」「多血質」 |
| 体力・代謝の傾向 | 「高い基礎代謝」「低代謝」「持久力」「回復力」 |
| 行動の物理的テンポ | 「瞬発的な動作」「緩慢なテンポ」「間欠的な行動テンポ」 |
| 身体部位への伝統的対応 | 「頭部への血流集中」「心臓系の強い拍動」「足先・リンパ系の負荷」 |
| 感覚器・神経系の身体的特性 | 「神経系の高い興奮性」「感覚器の鋭敏さ」 |

### 不採用語（NG例 — 他軸へ送る）

| 不採用語（伝統的に星座記述で頻出するが軸違反） | 本来の所属軸 | 理由 |
|---|---|---|
| 「自己管理力」「精緻なセルフコントロール」 | `cognitive_style` | 認知制御の話で身体性ではない |
| 「目標達成への意欲」「野心」 | `motivation_drive` | 動機の方向性であって体力ではない |
| 「共感力の高さ」「面倒見が良い」 | `relational_mode` | 対人関係パターン |
| 「気分屋」「感情の起伏が激しい」 | `emotional_response` | 情動表出パターン（ただし「気質としての発火点の低さ」は身体性なので embodied 採用可） |
| 「リーダーシップ」「カリスマ性」 | `relational_mode` または `motivation_drive` | 対人・動機混合 |

> 議論計画 §3.1 欠陥⑤（軸の純度違反、心理語の embodied 混入）への対策として、特に **心理語と身体語の境界** を本サンプルでは厳しく線引きしている。

## 3. 引用源の信頼性評価

### 一次文献（古典）

| 引用源 | 流派 | 役割 |
|---|---|---|
| Ptolemy, *Tetrabiblos*, Book I, Ch. 17（紀元2世紀） | ヘレニズム占星術の正典 | 12宮の元素・性質（熱乾/冷湿等）の根拠 |
| William Lilly, *Christian Astrology* (1647) | イギリス中世末期占星術 | 各宮と体液・身体部位の対応の英語圏定式化 |
| Vettius Valens, *Anthology*, Book I（紀元2世紀） | ヘレニズム占星術 | 獅子宮と心臓・脊椎等の身体対応の典拠 |

### 二次文献（学術・現代解説）

| 引用源 | 流派 | 役割 |
|---|---|---|
| Demetra George, *Ancient Astrology in Theory and Practice* (2019) | 現代古典復興派 | ヘレニズム期の身体対応の現代的整理 |
| Nicholas Campion, *A History of Western Astrology* Vol. II (2008, Continuum) | 学術占星術史 | バース大学占星術研究センター系の歴史的検証 |
| Robert Hand, *Horoscope Symbols* (1981) | 心理占星術派 | 各宮と臓器・神経系の対応 |
| Bernadette Brady, *Astrology, A Place in Chaos* (2006) | 古典・現代統合派 | 火星支配宮の身体的代謝の解説 |
| Liz Greene, *The Astrology of Fate* (1984) | 心理占星術派（ユング系） | 内分泌・リンパ系の心理生理学的対応 |

### 流派バランスの意図

- **ヘレニズム期一次文献（Ptolemy / Valens）を全カテゴリの基盤とする** — 体液論的気質は2500年の連続性があり、最も信頼性が高い。
- **中世（Lilly）で身体部位対応を補強** — 英語圏伝統の橋渡し。
- **現代心理占星術（Greene / Hand）は補助的に使用** — 一次文献だけでは記述が薄い末梢系・内分泌系のみ採用。

## 4. vector 配分の意図

### 配分結果

| vector | 件数 | カテゴリ |
|---|---|---|
| positive | 4 | aries, gemini, leo, sagittarius |
| negative | 3 | cancer, virgo, pisces |
| neutral | 5 | taurus, libra, scorpio, capricorn, aquarius |

### 配分根拠

| vector | 判定基準 | 適用 |
|---|---|---|
| positive | 当該軸（身体性）で「高エネルギー・活発・発露の強い」気質 | 火宮3つ（aries/leo/sagittarius）+ 神経系優位の風宮の代表 gemini |
| negative | 当該軸で「脆弱性・低エネルギー・疲弊しやすい」気質。**伝統医学的に体液の偏りが身体不調を生みやすい宮** | 月支配の cancer（保水性・むくみ）、消化器脆弱の virgo（冷乾の柔軟宮）、免疫脆弱の pisces（柔軟水宮） |
| neutral | 持久型・両義的・均整型。「強くも弱くもない」あるいは「強さと弱さが拮抗」する宮 | 固定土の taurus、活動風の libra、深部代謝の scorpio、活動土の capricorn、土・天王星両支配の aquarius |

> **議論計画 §3.1 欠陥②対策**: 単段 LLM 生成では negative が 0 件になりやすい（ポジティブバイアス）。本サンプルでは伝統医学（特に Lilly）で **明示的に身体脆弱性が記述される宮** を negative に意識的に配置した。

## 5. confidence 分散の意図

### 配分結果（実測 σ = 0.1361 ≥ 0.10 ✅）

平均 = 0.7500 / 標準偏差 = **0.1361**（Schema 制約 0.10 を上回る）

| 帯域 | 件数 | カテゴリ（confidence） |
|---|---|---|
| 中核必須 (≥ 0.85) | 4 | aries (0.92), leo (0.90), taurus (0.88), sagittarius (0.85) |
| 強く言及 (0.70-0.84) | 4 | virgo (0.82), capricorn (0.80), cancer (0.78), gemini (0.72) |
| 標準 (0.55-0.69) | 3 | scorpio (0.68), pisces (0.62), libra (0.55) |
| 部分的 (0.30-0.54) | 1 | aquarius (0.48) |

### 帯域ごとの判定根拠

- **中核必須**: 4元素3区分（火・土・風・水 × 活動・固定・柔軟）の中で、伝統占星術の身体対応記述が **最も豊富・一貫している宮**。aries（火活動）と leo（火固定）は心臓・血流など中核臓器対応が確立。taurus（土固定）と sagittarius（火柔軟）も体液・部位対応が広く言及される。
- **強く言及**: 体液論的記述はあるが、上記4つほど一貫性が高くないか、現代では言及頻度が下がっている宮。
- **標準**: 古典には記述があるが、流派による解釈の幅が大きい宮。
- **部分的**: aquarius は **古典の土星支配 vs 現代の天王星支配** で気質的記述が大きく分かれており、confidence を意図的に低くした。

> **議論計画 §3.1 欠陥①対策**: 単段 LLM 生成では confidence が 0.90-0.95 帯に飽和する（ルーブリック不在）。本サンプルでは **「言及頻度の流派横断的一致度」を判定基準** とし、4帯域に意識的に分散させた。

## 6. Gate 2（えんまさ）確認依頼事項

- [ ] **【Q1: 無明を晴らすか】** 各カテゴリの features が「自分の体質パターンへの解像度を上げる」言葉として機能するか。「ふわっとした星占い的記述」ではなく「自分の身体傾向の名指し」になっているか。
- [ ] **【Q2: 三毒を増幅しないか】** negative 配分（cancer / virgo / pisces）の features が「劣等感を煽る／不安を煽る」読まれ方をしないか。特に「免疫脆弱」「消化器脆弱」等の表現が三毒（特に瞋・痴）を増幅しないか。
- [ ] **【Q5: 良い人間関係に寄与するか】** 「自分は冷乾質だから消耗が早い」と腑落ちすることが、対人関係での自己理解・他者理解に繋がるか。
- [ ] **【流派バイアス】** ヘレニズム期一次文献に重心を置きすぎていないか。現代心理占星術（特に Greene 系）の補強が必要なカテゴリはあるか。
- [ ] **【牡羊座 features の主観確認】** aries の `["高熱量の胆汁質", "瞬発的な動作", "短期集中のテンポ", "発火点の低い気質", "頭部への血流集中", "急性の発熱反応", "回復の速い体力"]` が、実在の牡羊座の人物 2-3 名で主観一致するか。
- [ ] **【negative 配分への異論】** cancer / virgo / pisces を negative とした判定が、伝統解釈ではなく「現代の星占い記事のポジティブバイアス」と衝突する可能性。明示しておくべきか。
- [ ] **【aquarius 0.48 への異論】** 古典 vs 現代の支配星問題で confidence を最低にしたが、もっと高く（あるいは neutral から positive へ）置く解釈もありうる。

## 7. パイプライン実走時の利用方法

### Critique LLM（Step 4）との diff チェックポイント

| 観点 | 比較方法 | 乖離大の場合のパイプライン調整 |
|---|---|---|
| 軸純度 | features の心理語・対人語含有率 | extract.md プロンプトに「§2 不採用語表」を注入 |
| negative 見落とし | vector 配分が positive 偏重か | critique.md プロンプトに「negative 候補は cancer/virgo/pisces 系統」を hint 化 |
| 引用源充足 | primary_sources の type=book/academic 件数 | extract.md に「Step 1 本文の引用句をそのまま citation 化」を指示 |
| confidence 飽和 | 標準偏差が 0.10 未満 | extract.md に「§5 帯域定義表」を注入 |
| 本文-JSON 情報落差 | 本文の「脆弱性」記述が features に反映されているか | critique.md に「本文に xxx と記述があれば features に対応語が必要」ルールを生成 |

### 全 20 セル展開時の使い回し方針

- 本サンプルは **唯一の検証済みリファレンス**。動物占い・六星占術・MBTI の各セルでも、本書 §2-5 の枠組みをコピーして使用する。
- ただし「体系の伝統的支配概念」（4体液 / 60干支 / 6運命星 / 認知機能の4軸）は体系固有なので、その部分は各セルの rationale で個別に定義する。
