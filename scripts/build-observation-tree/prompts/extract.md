# vector 判定基準（最重要）

**negative の見落としと positive の過小評価、両方が頻出する欠陥。** 双方向バイアスを同等に警戒せよ。

## 基本基準

| vector | 判定基準 | 例 |
|---|---|---|
| `positive` | 適応的・建設的・本人と他者に資する特性 | 「行動力がある」「共感が深い」「整理力に長ける」 |
| `negative` | 不適応・自他を消耗させる・脆弱性として記述された特性 | 「衝動的に怒る」「他者の境界を侵す」「自己批判的」「うつ傾向」 |
| `neutral` | 二面性・文脈次第・価値判断保留 | 「内向的」「変化を好む」「孤独を好む」 |

## 中核 vs 副次の重み付け（重要 — 2026-05-27 実走で発見されたバイアス対策）

本文の各カテゴリは多くの場合、**気質・性向の説明（中核）** と **脆弱性・短所・典型的不調（副次）** の両方を含む。**vector はカテゴリの中核特性で判定する**。脆弱性記述が本文にあっても、それが副次的補足なら vector を negative に反転させてはならない。

| 本文構造 | vector 判定 |
|---|---|
| 気質中核 = positive、脆弱性が副次的補足として併記 | **`positive` を維持** |
| 気質中核 = negative、副次に positive 要素も併記 | **`negative` を維持** |
| 気質中核そのものが脆弱性ベース（例: melancholic 体液質 = 抑うつ傾向） | `negative` |
| 中核と副次が拮抗、流派により評価が分かれる | `neutral` |

**典型ミス（過剰 negative）**: 「牡羊座は瞬発力と熱量が中核（positive）だが、頭痛や急性炎症の脆弱性もある」と本文に書かれているとき、`vector = negative` と判定するのは誤り。中核の瞬発力・熱量で `positive` を維持し、脆弱性は features に 1-2 語含める程度にとどめる。

**典型ミス（過小 negative）**: 「乙女座は冷乾質で消化器の脆弱性が中核（negative 中核）」と書かれているのに、`vector = neutral` で逃げるのは誤り。中核が negative なら `negative` を選ぶ。

## 3値出現の必須性

> **体系全体で positive / negative / neutral の3値が全て出現することが必須。** positive と neutral だけになっていたら、本文を読み直して negative を探せ。逆に、全カテゴリが negative に偏ったら、positive 中核を見逃していないか再確認せよ。それでも見つからなければ「本文不足」と判断し抽出を停止せよ（後段でリトライされる）。

# confidence 判定ルーブリック（5段階）

| 値 | 条件 | 例 |
|---|---|---|
| 0.90-1.00 | 古典・現代の複数学派が一致、本文に明示的引用が2件以上 | 「胆汁質=熱・乾」(ヒポクラテス・ガレノス・伝統西洋医学一致) |
| 0.75-0.89 | 主要1学派の明示的記述、伝統一致 | 牡羊座の頭部・顔面への影響(占星医学伝統) |
| 0.60-0.74 | 主流解釈だが学派間に揺れ | 動物性格診断の生年月日対応 |
| 0.45-0.59 | 1学派のみ、もしくは現代心理学の検証少 | 六星占術の運命周期 |
| 0.30-0.44 | 異論あり / 解釈幅大 / 民間伝承レベル | 個別の小道具的解釈 |

> **0.90-0.95 に全カテゴリが固まる「飽和」を避けよ。** カテゴリ間で根拠の強さが違うはずなので、confidence の体系内標準偏差は 0.10 以上になる。

# primary_sources の抽出ルール

- 本文中に登場する**全ての引用源**を漏らさず列挙する（脚注・本文中の括弧書き含む）
- type は厳密に判定:
  - `book`: 出版された書籍（古典含む）
  - `academic`: 査読付き論文・学術書・大学出版物
  - `web`: ウェブ記事・ブログ・公式サイト
- `citation` は10文字以上、著者名 + 書名 + 巻号 or 年 を含める形式
- `url` は本文に明示されている場合のみ任意設定
- **書籍 or 学術が1件もない**カテゴリは抽出失敗とみなし、再抽出（次段リトライで再生成される）

# features 抽出方針

- **5〜10語、6-8 語を標準目安**: 全カテゴリで下限 5 語固定や中央値 6 語固定のテンプレ化は禁止。本文に7語の特徴記述があれば 7 語、4 語しか無ければ「本文不足」として最低 5 語を確保するため再読込せよ
- **各20文字以内**: 「瞬発的な運動エネルギー」(11文字) ○ / 「身体の活動性が顕著で常に何かを始めたがる傾向」(23文字) ×
- 軸境界違反語の除外（前述）
- 禁止語彙の除外（前述）
- **抽象語より具体語**: 「行動的」より「瞬発的な運動エネルギー」が望ましい
- **本文の情報密度を反映**: 本文の「気質・性向の説明」に 6 段落あれば features も 6 語以上、3 段落なら 5 語、というふうに源情報の密度を尊重せよ
